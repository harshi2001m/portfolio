# Harshani Madushani — Portfolio new

A responsive personal portfolio built with **HTML, CSS, and vanilla JavaScript**. No frameworks, build tools, or backend required.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, themes, and animations
- `script.js` — mobile navigation, theme toggle, typewriter, reveal effects, and scroll progress

## Run locally
Open `index.html` in a browser. For local development, you can also use the VS Code Live Server extension, but it is not required.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `harshani-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Personalize before publishing
Search in `index.html` and replace:
- `your.email@example.com` with your real email address.
- The GitHub and LinkedIn profile URLs with your profile links.
- The sample project titles, descriptions, and technology tags with your real projects.
- The education text with your institution, degree, and dates.
- Add or remove skills to reflect your actual experience.

The Google Fonts import is optional and requires an internet connection. The website itself works without it using fallback fonts.
